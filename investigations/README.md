# Investigations

This section contains the security investigations performed during the Home SIEM project.

Each investigation follows a structured SOC Analyst workflow including:

- Situation
- Initial Hypothesis
- Investigation
- Findings
- Response
- MITRE ATT&CK Mapping
- Lessons Learned

## Investigation 1 – Brute Force Login Activity (Event ID 4625)

Objective:
Detect and investigate repeated failed authentication attempts using Windows Security Event ID 4625.

Key Skills Demonstrated:

- Authentication log analysis
- Threat detection
- Event correlation
- SOC investigation workflow

## Investigation 2 – Suspicious PowerShell Activity (Event ID 4104)

Objective:
Monitor and investigate PowerShell activity using Script Block Logging.

Key Skills Demonstrated:

- PowerShell analysis
- Command execution review
- Threat hunting
- Event investigation

## Investigation 3 – Process Creation Activity (Sysmon Event ID 1)

Objective:
Monitor process execution activity and identify potentially suspicious process behavior.

Key Skills Demonstrated:

- Endpoint visibility
- Process analysis
- Command-line investigation
- Sysmon monitoring

## Investigation 4 – Registry Persistence Activity (Sysmon Event ID 13)

Objective:
Detect registry modifications associated with persistence techniques.

Key Skills Demonstrated:

- Persistence detection
- Registry monitoring
- Endpoint investigation
- MITRE ATT&CK mapping
